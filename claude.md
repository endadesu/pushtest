# Project Guidelines

## General
- Keep the implementation simple and easy to understand.
- Do not overengineer.
- Prefer small, focused changes.
- When making code changes, explain what changed and why.

## Frontend
- Use React functional components.
- Keep the UI clean, simple, and readable.
- Prefer clear button labels over ambiguous symbols.
- Improve spacing and layout when changing UI.
- Do not introduce unnecessary libraries.

## Backend
- Use Spring Boot for backend changes.
- Keep APIs RESTful and JSON-based.
- Keep controller, service, and model responsibilities clear.
- Todos are persisted in PostgreSQL via Spring Data JPA.

## Development Workflow
- Before adding a new dependency, explain why it is needed.
- When changing scripts or configuration, mention exactly what was changed.
- Keep instructions for running the app accurate and aligned with the actual files in the repository.

## Output Style
- Be concise but clear.
- If something already exists, say so explicitly.
- If an error is caused by local environment setup, point that out clearly.
